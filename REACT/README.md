# 💄 DivaDen - A MERN Stack E-Commerce Website

DivaDen is a full-featured e-commerce platform for beauty and skincare products. Built with the **MERN stack** (MongoDB, Express, React, Node.js), it offers a sleek frontend, secure authentication, and efficient backend APIs.

---

## 🖥️ Tech Stack

- **Frontend**: React.js, Vite, Tailwind CSS, Axios
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (with Mongoose)
- **Authentication**: JWT + bcrypt
- **State Management**: React Context API
- **Other Tools**: Git, GitHub, Postman, VS Code
